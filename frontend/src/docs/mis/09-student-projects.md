---
title: Supervising student projects
summary: Follow the projects you supervise, give feedback and get a report on every project in the school.
---

Students plan and build their own projects in Amashuri. Staff supervise them, comment on progress and confirm when a project is finished.

## Before you start

- **Assigned projects** lists a project when someone names you as its supervisor or adds you to its team.
- **All projects** is for staff who monitor projects across the school. If you do not see it, your role does not include it.

## See the projects assigned to you

1. In the menu, open **Workspace** and select **Assigned projects**.
2. Read the tiles under the title. Each one filters the list when you select it.
3. Use **Search**, **Your role**, **Stage** and **Sort** to narrow the list.
4. Switch between **Cards** and **Board** to change the layout.

| Tile | Shows |
|---|---|
| **Awaiting your review** | Projects waiting for your answer |
| **Overdue** | Projects past their planned date |
| **On hold** | Projects that are paused |

A project moves through stages: **Idea**, **Planning**, **Building**, **Testing** and **Completed**.

## Open a project

Select a project to open it. The tabs show its parts.

| Tab | What it holds |
|---|---|
| **Overview** | The summary of the project |
| **Plan** | Features and tasks |
| **Documents** | The concept note and other documents |
| **Progress** | Reports written after each work session |
| **Feedback** | Messages between you and the team |

## Give feedback

1. Open the project and select **Feedback**.
2. Choose **Comment** for a simple message.
3. Choose **Request changes** when the team must fix something. Say what should change.
4. Choose **Verify completion** when the finished project is confirmed. This choice appears only if you are allowed to verify.
5. Write your message and send it.

## Monitor all projects

1. Open **Workspace** and select **All projects**.
2. Use the views: **Dashboard** for the summary, **Projects** for the list and **Board** for the stages.
3. Filter by **Owner**, **Status**, **Class**, **Health** or **Review**.
4. Select **Excel** or **PDF** to download a report of the filtered projects.

> **Tip:** The **Health** filter finds projects with **No recent activity** or marked **Blocked**, so you know who to talk to first.

## If something goes wrong

- "Nothing assigned to you yet": nobody has named you as supervisor or team member.
- "Nothing matches these filters": select **Clear filters**.
- "You don't have access to students' projects": ask your school administrator.

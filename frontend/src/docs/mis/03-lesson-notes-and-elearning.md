---
title: Lesson notes and e-learning courses
summary: Write a lesson note, build a course from your scheme of work and make sure students can read both.
---

A lesson note is the reading material you give students for a topic. An e-learning course is where students open your notes, materials and quick checks, week by week.

## Before you start

- A school administrator must have assigned the subject to you.
- A course is built on a scheme of work. Write the scheme first, with its weekly entries.

## Create a lesson note

1. In the menu, open **Teaching** and select **Lesson Notes**.
2. Select **New Note**.
3. Choose the subject, the class and a title, and pick how to create the note.

| Choice | What it does |
|---|---|
| **Write myself** | Opens a blank note in the editor. |
| **Generate with AI** | Drafts the note from the learning outcomes you tick. It is saved as a draft for you to review. |
| **Upload a PDF** | Uses a file you already prepared. The PDF is read-only. |

The editor saves as you type. If you see **Not saved — retry**, select it before you leave.

## Publish a note

1. Open the note and check the content.
2. Select **Publish**. The class of the note can now read it.

**Share** gives a published note to hand-picked students or another class. **Unpublish** takes the note back.

## Set up a course

1. Open **Teaching** and select **E-Learning**.
2. Find the scheme for your subject and class.
3. Select **Set up course**.

The weeks come from your scheme of work, pre-filled with the notes and materials you already have.

## Fill and publish the course

1. Open the course and choose a week.
2. Select **Add** to pick a lesson note, a material or a new item such as a **Page**, **Video**, **Link** or **Quick check**.
3. Select **Publish the whole course**.
4. Switch each week on when it is ready.

> **Important:** Students see a week only when the course is published and the week is switched on. A note that is still a draft stays closed to students until you publish the note.

Select **Preview** to see the course as a student.

## Check that a note reaches students

In the **Lesson Notes** list, each note carries a label. **Live** means students can read it. **Add to e-learning** means you still need to choose its week. Select the label to fix it.

## If something goes wrong

- **Publish** is greyed out on a note: add some content first.
- **Set up course** is greyed out: the scheme has no weekly entries yet.
- Students see nothing in a course: it is still a draft. Publish the whole course.

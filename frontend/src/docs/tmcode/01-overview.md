---
title: What TMCode is and how to sign in
summary: Understand what TMCode does for you as a teacher, install it, and sign in for the first time.
---

TMCode is the Amashuri code editor. It is a desktop app where students write, run and hand in the coding work you set in Task Mentor, and where you grade that work beside the code.

## How TMCode fits with Task Mentor

- You create coding assignments and quizzes in Task Mentor.
- Students open that work in TMCode. Their work saves to Task Mentor by itself, and they hand it in with **Submit**.
- You grade in TMCode, with the code beside the grade form. Grades are saved to Task Mentor.
- Exams open from Task Mentor, never from the TMCode **Home** page.

TMCode is also a general code editor. You and your students can open any folder and practise with **Open Folder**, without an assignment.

## Before you start

- You need your school account, the one you use for Amashuri and Task Mentor.
- You need TMCode installed on your computer. It runs on macOS, Windows and Linux. Ask your school administrator for the installer.

## Install TMCode

1. Run the installer.
2. On macOS, if the system says TMCode "can't be opened", go to System Settings, then Privacy & Security, and choose **Open Anyway**.
3. On Windows, if you see "Windows protected your PC", choose **More info**, then **Run anyway**.

## Sign in

1. Open TMCode. It opens on **Home**.
2. Choose **Sign in**. Your browser opens.
3. Finish signing in in the browser with your school account, then go back to TMCode.

One sign-in covers Amashuri and Task Mentor. After your first sign-in, TMCode remembers that you teach, so **Grading** is the first icon on the left.

> **Tip:** If the browser did not open, TMCode offers **Open the Browser Again** and **Copy Sign-in Link** while it waits.

## Keep TMCode up to date

Updates install from inside the app. Open the Help menu and choose **Check for Updates**. TMCode never updates during an exam.

> **Note:** In **Grading** you see the code assignments and coding questions of your own subjects.

title: Set coding work that students open in TMCode
summary: Give an assignment starter files from TMCode and follow how your class is doing.
---

Use this guide to prepare a code assignment so that students start from your files, and to see who has started, handed in or been graded.

## Before you start

- Create the code assignment in Task Mentor first. TMCode shows the assignments of your subjects, it does not create them.
- Sign in to TMCode with your school account.

## Give the assignment starter files

Starter files are the files every student gets when they begin.

1. In TMCode, open the project you want students to start from. It must be a project saved to Task Mentor.
2. Open the assignment's page from **Assignments**.
3. Open the **…** menu and choose **Use Open Project as Starter…**.
4. Pick the assignment in the list.

## What students do

1. On **Home**, the student sees **Next up** and chooses **Start**, or **Continue** if they already began.
2. TMCode asks where to save the project, then opens your brief beside the code. The brief is the page with your instructions.
3. Their work saves to Task Mentor by itself. The brief says "Saved online".
4. They choose **Submit** on the brief to hand in. They can choose **Withdraw to Edit** until the work is graded.

Until a student submits, TMCode shows an orange **Not submitted** label on the assignment.

## Follow your class

Open the assignment's page in TMCode. It shows four numbers:

| Number | Meaning |
|---|---|
| **Students** | Everyone who has the assignment |
| **In progress** | Started but not handed in |
| **To grade** | Handed in and waiting for you |
| **Graded** | Already graded |

The main button on the page is **Grade**, with the number waiting in brackets.

## If something goes wrong

- **A student worked in their own folder, not in the assignment.** They can connect it with **Connect This Folder to an Assignment…**.
- **TMCode says to open a Task Mentor project.** The open project is not saved to Task Mentor. Save it there first, then try again.
- **A student says they submitted but you see nothing.** Ask them to check the banner over their code. If it still reads **Not submitted yet**, they must choose **Go to Submit**, then **Submit**.

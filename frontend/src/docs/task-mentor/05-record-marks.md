---
title: Record marks from class work and tests
summary: Add an assessment done on paper, enter each student's mark, and mark students absent or exempt.
---

Use the **Grades** page to record marks for work done outside Task Mentor, such as class work, homework and written tests.

## Before you start

You need to teach the subject. Check the year and term in the top bar.

## Add an assessment

1. Select **Grades**, then **Add Assessment**.
2. Select a subject.
3. Choose the **Assessment Type**: **Class Work**, **Group Work**, **Homework**, **Midterm**, **Participation** or **CA End Of Term Exam**.
4. Enter the **Assessment Number** (for example 1 for the first midterm), choose the date and enter the **Maximum Marks**.
5. Leave **Add to Final Grade** ticked if the marks should count.
6. Select **Save**.

## Enter the marks

1. On the **Grades** page, expand the subject and select **Record scores** on the assessment.
2. Type each student's mark. Press **Enter** to move to the next student.
3. Select the **Save** button at the bottom. It shows how many changes are waiting.

Ways to go faster:

- **Fill max** gives every empty row the maximum mark.
- Paste a column from Excel or Google Sheets into a row. It fills that row and the rows below.
- Press `Ctrl+S` (or `Cmd+S` on a Mac) to save.

## Mark a student absent or exempt

| Status | Effect | Key |
| --- | --- | --- |
| **Absent** | Counts as 0 on the report card | `A` |
| **Exempt** | Left out of the report card | `E` |

With the cursor in the student's mark box, press the key, or choose the status in the row. Press **Backspace** to go back to a mark.

## Map the assessment to the report card

Mapping means choosing the report card category an assessment counts in.

1. On the **Grades** page, find a subject with unmapped work.
2. Select the **Map** button on the subject row. Task Mentor suggests a category for each assessment.
3. Change any suggestion, or choose **Skip**, then confirm with **Map**.

## If something goes wrong

- You left the page before saving: unsaved marks stay on that device as a draft. When you return, select **Restore** to bring them back, or **Discard**.
- You typed marks in the wrong rows: select the undo button to return every unsaved change to the saved marks. Saved marks stay as they are.
- A mapping menu is locked: the assessment is marked as part of another assessment, so it cannot be mapped on its own.

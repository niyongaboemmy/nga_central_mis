---
title: Grade submitted work
summary: Find work waiting for a grade and mark assignments, quizzes and code projects.
---

Grading gives each submission a score and feedback that the student can see.

## Before you start

You can grade work in subjects you teach.

## Find what needs grading

1. Select **To grade** in the menu. The number beside it is the count of items waiting.
2. Filter by **All**, **Assignments** or **Quizzes**, or by subject.
3. Select **Grade** on an item. Task Mentor opens the right grading screen for it.

## Grade an assignment

1. Open the assignment and go to **Submissions**.
2. Select a student's submission to open it.
3. Under **Grading**, enter the **Marks awarded**. If the assignment has a rubric, score each criterion and select **Use rubric total**.
4. Write your **Feedback**.
5. Select **Finalize Grade**.

If a student saved work but never submitted it, select **Mark as submitted**. You can then grade it.

> **Note:** **Draft marks & feedback** asks AI to suggest marks and feedback from the work and your rubric. Nothing is saved, and the student sees nothing, until you save the grade.

## Grade a quiz

1. Open the quiz and select **View Submissions**.
2. Select **Grade** on an attempt with a **Pending** grade (the button reads **Adjust** once it is graded).
3. In **Adjust Marks**, set the score for each question, add **Instructor Feedback** if you wish, and select **Save Adjustments**.

To enter marks by hand for a student who has not been graded yet, select **Record Manual Marks**. Choose the student, enter the marks, then select **Approve & Save**.

## Grade a code project

Code assignments and coding quiz questions open in a full-screen grading workspace.

1. Choose a student from the list. Filter by **To grade**, **Graded**, **Working** or **Not started**.
2. Review the work with the **Code**, **Activity** and **Details** views. **Preview** and **Run** appear when the project can be previewed or run.
3. Score every criterion.
4. Write the **Feedback to the student**.
5. Select **Save & next** to save and move to the next student to grade.

## If something goes wrong

- You cannot save a grade: enter the marks first. In the code workspace, every criterion needs a score.
- A grading panel shows "You can view this work but not grade it": only a teacher of the subject, the creator of the work or a super administrator can grade.
- You closed the code workspace before saving: your unsaved scores are kept on that device and restored when you return to the student.

---
title: Create and manage assignments
summary: Set an assignment for a subject, add a grading rubric, publish it and control its status.
---

An assignment is a piece of work students hand in by a due date, as files, written text or a code project.

## Before you start

You need to teach the subject. Check the year and term in the top bar.

## Create an assignment

1. Select **Assignments**, then **Create Assignment**.
2. Under **Basics**, enter a **Title**, choose the **Course** and set the **Due date & time**.
3. Enter the **Max score** and choose a **Status**: **Draft** to keep preparing, or **Published** to show it to students.
4. Under **How students submit**, choose the **Submission type**.
5. Under **Instructions**, describe the task, the steps and what to hand in.
6. Under **Grading rubric**, add a rubric: a list of criteria, each worth some marks. Select **Add criteria yourself**, or **Generate from the description** to let AI draft one.
7. Under **Resources for students**, attach handouts or starter files. Each file can be up to 10 MB.
8. Select **Create assignment**.

## Submission types

| Type | What students do |
| --- | --- |
| **File & text** | Upload and/or write |
| **File only** | Students upload files |
| **Text only** | Students write online |
| **Code project** | Students write and submit a code project in TMCode |

## Change the status

On the **Assignments** page, each assignment you created has a status menu.

| Status | Meaning |
| --- | --- |
| **Draft** | In preparation |
| **Published** | Live for students |
| **Completed** | Period ended; no more submissions |
| **Removed** | No longer available |

## Keep marks out of totals

Some work is one part of a bigger assessment, such as a section of an exam. On the **Assignments** page, open the assignment's **Marks status** menu.

- **Counted**: marks count in dashboards, rankings, reports and report cards.
- **Part of another assessment**: graded here and shown to students, but left out of every total.

To edit an assignment, open it, select **Edit Assignment**, then **Save changes**.

## If something goes wrong

- The form will not save: read the message under the field. The due date must be in the future.
- The rubric is refused: the criteria must not add up to more than the max score, and every criterion needs a name and marks above 0.
- You cannot change the status: only the teacher who created the assignment, or a super administrator, can edit it or change its status.
- **Generate from the description** is greyed out: AI is switched off for your account or school.

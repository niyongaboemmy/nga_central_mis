---
title: Create a quiz
summary: Build a question bank, create a quiz, set its timing and rules, and publish it to students.
---

A quiz is a set of questions students answer online, mostly marked automatically.

## Before you start

You need to teach the subject. Questions live in the subject's question bank, so you can reuse them.

## Add questions to the question bank

1. Select **Question Bank** and choose a subject.
2. On the **Questions** tab, add questions in one of these ways.

- **Add Question** opens the form for one question. Pick the type (for example **Single Choice**, **True/False** or **Short Answer**), then set the points and difficulty.
- **Import** loads questions from a Word or Excel file.
- **AI Generate** drafts questions for you. Choose **Course resources** or **Upload a document** (PDF or DOCX), pick the question types and how many, then review the drafts and save the ones you want to the question bank. One run makes at most 60 questions.

## Create the quiz

1. Select **Quizzes**, find the subject and select **New quiz**.
2. Enter the **Quiz Title**, **Description** and **Quiz Type** (**Quiz**, **Assessment**, **Homework** or **Exam**).
3. Under **Quiz Settings**, fill in the options in the table below.
4. To watch students by camera during the quiz, tick **Enable online proctoring for this quiz**.
5. Select **Create Quiz**.

| Setting | What it does |
| --- | --- |
| **Maximum Attempts** | Leave empty for unlimited attempts |
| **Overall Duration (Optional)** | One timer for the whole quiz. Leave empty to time each question on its own duration |
| **Available From** and **Available Until** | The window when students can take the quiz |
| **Randomize question order** | Each student gets their own order |
| **Show results immediately after completion** | Students see results as soon as they submit |
| **Require instructor manual grading** | Grades stay hidden until you review them |

## Add questions to the quiz

1. Open the quiz from the **Quizzes** page.
2. Select **Add from Bank**. Set your filters, the **Target question count** and **Points per question**, then select **Run Algorithm Search**.
3. Tick the questions you want and select the **Assign** button at the bottom.
4. To write a new question directly, select **Add Question**.
5. Drag questions to reorder them.

## Publish

1. In the quiz, select **Edit Quiz**.
2. Set **Status** to **Published** and select **Save Changes**.

## If something goes wrong

- The quiz will not publish: a quiz needs at least one question before it can be published.
- You see **View only**: only the quiz's creator or a super administrator can edit it or change its status.
- **AI Generate** is greyed out: AI is switched off for your account or school.

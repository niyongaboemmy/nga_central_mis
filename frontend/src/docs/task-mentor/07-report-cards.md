---
title: Prepare and publish report cards
summary: Take a class's report cards from draft to published by submitting marks, adding comments, reviewing and approving.
---

A report card moves through four statuses: **Draft**, **Reviewed**, **Approved** and **Published**. Students and parents see a card only after it is published.

## Before you start

- Record your marks and map each assessment to a report card category on the **Grades** page.
- You only see the actions your role allows.

## See where each class stands

1. Select **Report cards**.
2. Read each class's stage: **Collecting marks**, **Ready to review**, **Awaiting approval**, **Ready to publish** or **Published**.
3. Use **Classes I teach** or **Needs attention** to shorten the list, then open a class.

The class page lists **What still needs doing** and shows every student's card.

## Submit your subject's marks

1. On the class page, under **Subjects**, select your subject.
2. If marks are missing, choose for each one: **I'll record it**, **Absent (counts 0)** or **Exempt (left out)**.
3. Select **Submit marks**.

## Add comments and attributes

1. On the class page, select **Write comments**.
2. Fill in attendance days. **Import attendance** pulls the day counts from the attendance registers.
3. Rate each student's behaviour and attributes, and write the comment.
4. Select **Save All**.

## Review, approve and publish

1. On the class page, tick the cards to act on.
2. Select **Mark reviewed**. This sends the cards for approval.
3. Select **Approve**, then confirm with **Approve and lock**. Marks, comments and attributes can no longer change.
4. Select **Publish**, then **Publish now**. To release the cards later, set a date under **Or release at** and select **Schedule**.

## Send a card back

| Action | Use it when |
| --- | --- |
| **Return to draft** | A reviewed card needs a correction |
| **Unpublish** | A published card must be hidden again |
| **Reopen to draft** | An approved or published card must change |

Each of these asks for a reason. The reason is saved in the card's history.

## Settings and templates

Staff who can approve cards also see **Card settings** and **Templates** on the **Report cards** page.

- **Card settings** holds the grading scale, category weights, pass mark and behaviour attributes.
- **Templates** chooses the school's report card builder and how every card looks.

## If something goes wrong

- A card cannot be changed: only draft cards can be changed. Return it to draft first.
- A subject shows **No assessments mapped**: map its assessments on the **Grades** page.
- Some cards are refused: Task Mentor lists each refused card with the reason. The **Has blockers** filter shows them.
- A subject teacher needs to change submitted marks: open the subject and select **Reopen for changes**.

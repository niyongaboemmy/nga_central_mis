---
title: Correct or add a register
summary: Change a register that is already saved, or record a session that is not on your timetable.
---

Use this guide when a saved register has a mistake, or when you taught a session that the timetable does not show, such as a make-up class.

## Correct a saved register

1. In the menu, select **Attendance**, then **Attendance Calendar**.
2. Open the **Day** view and go to the date of the lesson.
3. On a lesson marked **Done**, select **Edit**.
4. The register tells you how many students were marked, who marked it last and when.
5. Change the status or the note of the students concerned.
6. Select **Update**. The button shows how many students you changed.

To undo your changes before saving, select **Discard**.

> **Important:** If another teacher marked the register, Tendo asks **Overwrite another teacher's register?** Select **Overwrite** only if you are sure. Your changes replace theirs, and the previous values stay in the register's history.

## Find a register in the history

1. In the menu, select **Attendance**, then **Attendance History**.
2. Type a student name or ID in the search box, or choose a class.
3. Narrow the list with the status and session filters.
4. On the row you want, select **Open**. The register for that session opens so you can correct it.

You can also select **Export CSV** or **Export JSON** to download the list you see.

## Record a session that is not on the timetable

1. In the menu, select **Attendance**, then **Attendance Calendar**.
2. Select **Record a session**.
3. Under **Session type**, choose **Homeroom (daily)** or **Subject / course**.
4. Choose the **Class**. For a subject session, also choose the **Subject**.
5. Choose the **Date**. You cannot choose a future date.
6. Choose the **Period**: **Morning**, **Afternoon** or **Evening**.
7. Select **Open register**, mark the students, then select **Save register**.

## See the details of a lesson

Select any lesson in the calendar to open its page. It shows the date, time, class, room and teacher. Under **Class attendance** you see the totals, and under **Register** the mark of each student. From this page you can select **Take register** or **Update register**. Select **Back to calendar** to return.

## If something goes wrong

- **You aren't the assigned Class Teacher of any class.** Only a class teacher can record a homeroom session. Choose **Subject / course** instead.
- **This lesson isn't on the timetable.** The lesson may have moved, or the academic period in the top bar may not match the date.
- The **Subject** list is empty until you choose a class.

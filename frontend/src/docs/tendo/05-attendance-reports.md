---
title: Read attendance reports
summary: Build, read, print and export the attendance report of a class or a subject.
---

The attendance report shows, for one class and one register, the mark of every student on every recorded day.

## Build a class report

1. In the menu, select **Attendance**, then **Attendance Report**.
2. Keep **By Class** selected.
3. Under **Pick a class to build its report**, select the class, for example "Senior 4 A". If you are the class teacher of one class, Tendo opens it for you.
4. Choose the register: **Morning check** or one of the class's subjects, for example "Mathematics".
5. Choose the dates: **Last 2 weeks**, **Last 30 days** or **Full term**. You can also set the two dates yourself.

## Build a report by subject

1. Select **By Subject**.
2. Select a subject. Tendo lists the classes that study it, with their attendance rate.
3. Select a class to open its report for that subject.

## Read the report

| Part | What it tells you |
| --- | --- |
| **Class average** | The attendance rate of the whole class |
| **Students tracked** | How many students are in the report |
| **Days recorded** | How many days have a register |
| **At risk** | How many students have a low attendance rate |
| **Students who need attention** | A chart of the lowest attendance rates in the class |
| **Register** | One row per student, one column per recorded day |

In the **Register** table, each day shows the first letter of the mark: P for present, A for absent, L for late, E for excused. A dash means no mark was recorded that day. The last columns give each student's totals, **Rate** and **Comment**.

- Select **Student** or **Rate** in the table header to sort.
- Type in **Search students…** to find one student.
- Under the chart, select the link that starts with **Show all** to see the whole class.

## Print or export

- Select **Export CSV** to download the table.
- Select **Print / Save PDF** to print the record or save it as a PDF.

## School-wide figures

In the menu, select **Insights**, then **Reports**. This page shows the **Overall Rate**, the **Attendance rate by class**. A class is **Exemplary** at 90% or more, **Acceptable** from 80% to 89% and **Critical** below 80%.

## If something goes wrong

- **No attendance recorded for this register in the selected range.** Choose a longer date range, or check that the registers were taken.
- **No classes to report on this term.** Check the academic period in the top bar.

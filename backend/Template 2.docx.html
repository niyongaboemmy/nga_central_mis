Development/Body

LO1: Selecting Design Objects

Trainer’s Activities:

  • Demonstrate the Selection Tool and Direct Selection Tool.
  • Explain selecting single vs multiple objects.
  • Show common selection mistakes and solutions.

Learners’ Activities:

  • Practice selecting objects in a sketch.
  • Use different selection techniques.
  • Identify selected anchor points and objects.

LO2: Moving and Aligning Objects

Trainer’s Activities:

  • Demonstrate moving objects using mouse and keyboard.
  • Explain alignment tools (left, center, right, top, bottom).
  • Show snapping and smart guides.

Learners’ Activities:

  • Move objects to different positions.
  • Align objects evenly.
  • Apply alignment tools to improve layout.

LO3: Grouping, Ungrouping, and Layering

Trainer’s Activities:

  • Explain grouping and ungrouping objects.
  • Demonstrate layering using the Layers panel.
  • Show how layering affects design order.

Learners’ Activities:

  • Group related objects.
  • Ungroup when necessary.
  • Arrange objects using layers.

LO4: Creating Balanced Layouts

Trainer’s Activities:

  • Demonstrate organizing objects for balance and clarity.
  • Explain visual hierarchy and spacing.
  • Show best practices for clean GUI layouts.

Learners’ Activities:

  • Arrange sketch elements into a balanced layout.
  • Adjust spacing and alignment.
  • Finalize layout for presentation.

Summary and Plenary

Trainer’s Activities:

  • Summarize key concepts:
    • Object selection
    • Alignment and arrangement
    • Grouping and layering
  • Ask oral questions:
    • “Why is grouping important in design?”
    • “How does alignment improve readability?”
  • Emphasize precision and organization in GUI design.

Learners’ Activities:

  • Present their arranged designs.
  • Share challenges faced and solutions applied.
  • Write three takeaways in their notebooks:
    1. One selection or alignment tool learned
    2. One layout improvement made
    3. How arranging objects improved their design
